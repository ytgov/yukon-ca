# Playwright UAT checks

Automated checks corresponding to [`docs/d11-uat-test-plan.md`](../../docs/d11-uat-test-plan.md). Runs in both headed Chromium and headed Firefox so you can watch it work.

## Setup

```bash
npm install
npx playwright install
```

## Run

```bash
npm test
```

Defaults to this project's local ddev URL. To check a different environment:

```text
BASE_URL=https://yukon.cms-uat.yukon.ca npm test
```

`npm run test:report` opens the last HTML report.

## Notes

- Role-based checks (content moderation, translation editing, permissions, etc.) log in via a fresh one-time login link generated by `ddev drush uli` on every run — this requires ddev to be running for this project, targeting whichever site the link is generated against. Running these against an environment other than local ddev (e.g. UAT) requires drush access to that environment's database, or those specific tests should be run manually there instead.
- See [`docs/d11-automated-test-results.md`](../../docs/d11-automated-test-results.md) for the last full run's findings.
